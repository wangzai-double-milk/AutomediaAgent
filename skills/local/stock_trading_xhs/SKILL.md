## 一、封面公式（5种爆款钩子）

### 1. 收益诱惑型
- 公式：大额数字 + 超高收益率 + 真实账户截图
- 示例："61万资产，月收益51.76%"
- 配色：橙红背景+米白大字
- 适用：有实盘成绩的博主

### 2. 身份共鸣型
- 公式：普通人标签 + 收益叙事 + 干货数量承诺
- 示例："炒股带娃5年，20w→200w，总结8条铁律"
- 配色：浅粉渐变+黑字+浅蓝高亮数字
- 适用：人设型博主（宝妈/打工族/学生）

### 3. 反常识反差型
- 公式：极低金额/浮亏截图 + 疑问/反转
- 示例："10.49元持仓" / "浮亏6000但当日盈利739"
- 配色：保留APP原生配色+少量软萌贴纸
- 适用：新手/实盘记录

### 4. 干货清单型
- 公式：数字量化 + 技能承诺 + 手绘风排版
- 示例："13大量价口诀，吃透量价关系" / "18种K线信号，一眼看懂涨跌"
- 配色：清单式排版+图标+彩色关键词标注
- 适用：知识类博主

### 5. 指路推荐型
- 公式：痛点 + 解决方案 + 信息差
- 示例："想学炒股可以去B站死磕这几位博主"
- 配色：极简纯文字+浅粉背景
- 适用：资源整合类

### 通用设计纪律
- 核心钩子放封面视觉中心/上半部分
- 柔和配色（浅粉/奶白）+ 粗黑大字（适配女性用户）
- 一张封面只放1个核心卖点
- 真实截图 > 网图模板

## 三、选题策略

### 高点击选题公式
1. **数字冲击**："X条铁律""X分钟学会""X个方法"
2. **身份标签**："宝妈/打工人/学生/新手"
3. **收益叙事**："从X万到X万"
4. **痛点共鸣**："你是不是也…""散户的通病"
5. **反向避坑**："千万别…""99%的人不知道"

### 选题节奏建议
- 每周：1篇干货清单（收藏驱动）+ 1篇实盘记录（追更驱动）+ 1篇互动话题（评论驱动）
- 干货清单是长尾流量主力，实盘记录建立信任，互动话题拉升权重
