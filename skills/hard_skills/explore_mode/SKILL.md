# 陌生环境探索引擎（Explore & World-Modeling）

> **当 Agent 落到一个还不熟的平台时（没有专用工具、`memory/world_model/<platform>.md` 也没有），走这里。**
> 像人第一次用一个新 App：不去读它的 API，而是**扫一眼→猜→试→看反应→在心里建立"这个平台怎么用"的地图→熟了之后闭眼操作→把反复成功的流程固化**。
> 本引擎依赖 [`../perception_action/SKILL.md`](../perception_action/SKILL.md)（眼睛+手）执行每一步动作。

## 何时进来
- 用户要在一个**没有专用方言**的平台做事（不是小红书）。
- 有平台但 `memory/world_model/<platform>.md` 不存在或很薄 → 边做边补。
- 用户显式说"去研究下这个 App/网站怎么用"。
- 任何模式（研究/运营）落到陌生平台需要操作时，由它们借道进来。

## 探索循环（O-H-P-O-M-E-C）

```
① Orient 定向    我在什么平台/什么页面？整体长啥样、能干什么？
                 → web_learn_page() 认页面 + web_scan 读文本；先建立"我在哪"
② Hypothesize 假设  结合当前目标 → "要达成 X，我应该点哪/找什么/分几步"
                    → 写不出假设 = 缺方法 → 走渠道经纪层先查"别人在这平台怎么做X"
③ Probe 试探     用 web_visual_click / web_visual_fill 动一下（最小可逆的一步）
④ Observe 观察   页面变了没？变成了什么？符合假设吗？(看 verified + 再 scan/learn 一次)
⑤ Model 建模    把"这个平台·这种页·这个元素·这个后果"写进世界模型(见下)。
                假设错 → 修正模型，回 ②
⑥ Exploit 利用   模型够确定后，按沉淀的步骤直接做（元素已结晶进 selector 缓存，免视觉）
⑦ Crystallize 结晶  一段反复成功的完整流程 → 固化成世界模型条目 / 平台 SOP / 工具(L3)
        └─ 模型/缓存失效（平台改版） → 退回 ① 重新探索（自愈）
```

要点：
- **每次只试最小、最可逆的一步**，看清反应再走下一步——别一次点一串不可逆操作。
- **不可逆操作（发布/删除/付款/关注真人）在探索期一律先停下确认**，别拿用户账号做破坏性试探。
- 试探卡住（连续失败/找不到入口）→ **不是硬试**，去渠道经纪层查"这个平台怎么做这件事"，或 `ask_user`（RULES：3 次失败请求介入）。

## 世界模型：探索的产物（L2 沉淀）

每个平台维护一份 `memory/world_model/<platform>.md`（首次探索时创建，用 `file_write`；持续探索时用 `file_patch` 增量补）。建议结构：

```markdown
# <platform> 世界模型 (last_updated: <date>)
## 一句话画像
这个平台是什么、擅长承载什么内容、主要用户是谁。
## 关键页面地图
- 首页/推荐流：URL 形态、布局、能干什么
- 搜索：搜索框在哪、结果页结构、有哪些筛选
- 内容详情：正文/评论/互动按钮的位置与加载方式
- 创作/发布：入口在哪、几步、有什么坑（如必须先存草稿）
- 个人/数据中心：粉丝/播放/互动数据在哪看
## 已验证的操作流程（可直接复用）
- 「发一条内容」：第1步…第2步…（哪些元素已结晶进缓存）
- 「抓一条内容的正文+评论」：…
## 平台机制与信号
- 推荐/流量机制（如完播率、互动率），爆款信号长什么样
- 风控红线、发布规则、token/登录注意事项
## 已知坑 / 失败记录
- 什么操作会失败、改版导致哪些 selector 失效过
```

> 世界模型 = Agent 对这个平台的"心智地图"。**它越完整，下次在这个平台就越像老手。** 这正是"像人一样越用越熟"的载体。

## 从探索到方言（L2 → L3 的进阶）
当某平台的世界模型足够成熟、某些流程高频又稳定：
- 把该平台的操作 SOP 单独立成 `skills/hard_skills/<platform>_*/SKILL.md`（参考小红书 `xhs_*`）。
- 把高频读数据/操作结晶成专用工具（`create_skill` 或脚本），从"每次视觉操作"升级为"确定性快路径"。
- **小红书 `xhs_*` 就是这条路走到头的样板**：它本质是"在小红书上探索熟练后结晶出的方言"。

## 纪律
1. 陌生平台**先建立世界模型再大干**，别假装懂它的 UI 凭空操作。
2. 每一步**最小可逆 + 验证反应**；不可逆操作先停下确认。
3. 卡住先查（渠道经纪层）不硬试；3 次失败请求用户介入。
4. **跑通就沉淀**：每段成功流程都要写回世界模型，否则下次又得从零摸。
5. 探索产出的事实/机制结论要可追溯（来自哪次试探/哪篇参考）。
