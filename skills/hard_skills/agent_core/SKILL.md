# Agent Core · Router

本 Skill 只做路由。完整依赖边界见 `skills/registry.json`。

## 1. 识别目标

从用户原话选择一个主结果：

| 结果 | 主工作流 |
|---|---|
| 找信息、比较、总结、调研 | `research_mode` |
| 策划选题/脚本/商业广告，或持续运营账号 | `operate_mode` |
| 审图并形成可发布内容 | `xhs_review` |
| 小红书单独搜索/读取 | `xhs_search` |
| 抖音浏览、搜索、查看视频 | `douyin_browse` |
| 单独点赞、收藏、评论、回复 | `xhs_interact` |
| 已有素材与文案，直接发布 | `xhs_publish` |
| 通知、自己作品、数据或账号管理 | `xhs_manage` |
| 未知平台上的单点操作 | `explore_mode` |

一次只选一个主工作流。用户明确要求多个独立结果时，拆成顺序任务，不并行加载多本工作流。

## 2. 识别平台

- 已有平台能力：使用对应 capability。
- 没有平台能力：使用 `explore_mode` 完成当前任务。
- 跨平台任务：主工作流不变，各平台只是不同数据源或发布目标。
- 用户未指定平台：按内容形态选择，无法合理推断时再询问。

## 3. 风险检查

- 搜索、阅读、分析、生成本地草稿：直接执行。
- 点赞、收藏等可撤销动作：用户明确要求后执行并验证。
- 公开发布、删除真实内容、付费投放：核对用户授权及目标。已明确授权的范围不重复询问。
- 小红书发布默认“仅自己可见”，可以按明确参数选择公开或互关好友可见。

## 4. 路由完成即停止

选定主工作流后，读取该 Skill 并由它继续编排。不要在 Router 中复制工作流步骤，
不要再回到本 Skill，除非用户在任务中改变了最终目标。
