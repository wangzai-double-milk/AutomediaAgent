# Git/GitHub 内容创作 SOP

> 基于 2026-06-15 对小红书+抖音 Git 赛道 Top 博主的调研沉淀

## 1. 选题优先级

1. **AI+Git**（Vibe Coding 时代必学）→ 当前最大红利窗口
2. **职场Git**（入职必会/团队协作）→ 刚需，收藏率高
3. **GitHub开源项目推荐** → 周更可预期，建立订阅心智
4. **Git踩坑/避雷** → 反向痛点，互动率高
5. **Git故事/历史** → 知识+情感，出圈潜力

## 2. 小红书创作模板

### 标题公式（3选1）
- 痛点反问：`[痛点场景]？[解决方案]` 例："代码总丢？吉伊卡哇教你Git保姆级教程！"
- 场景代入：`当[角色]让你[做某事]..` 例："当mentor让你新开一个分支管理你的代码.."
- 权威背书：`[身份/数据] + [价值主张]` 例："1K+Star的开源项目能给一个大学生带来什么"

### 视觉风格
- 漫画/IP风：用热门IP角色讲技术，降低门槛（GeekZero 吉伊卡哇 4404赞）
- 信息图/截图：终端截图+标注+分步骤，收藏率极高
- 数据卡片：GitHub项目排行榜，信息密度高

### 文案结构
```
[开头] 一句话戳痛点/给价值
[正文] 分点展开，每点1-2句，带emoji
[结尾] 引导互动（"还想看什么？评论区告诉我！"）
[标签] 垂直(#git #github #程序员) + 流量(#AI #教程 #干货 #vibecoding)
```

### 发布后
- 前30分钟积极回复评论
- 评论区深度提问逐一回复

## 3. 抖音创作模板

### 开头（前5秒）
- 直接给价值："本期视频带来一个XXX大串讲"
- 痛点故事："今天干活时，突然看到大群里有人艾特我..."
- 反常识："一个天才10天写出的工具，影响了开发行业整整20多年"
- 场景代入："入职必会之git操作，应届、实习生必会！"

### 制作模式
- **动画讲解**（最佳，技术爬爬虾 27.4万赞）：用动画演示Git工作流
- **屏幕录制+旁白**：IDE实操，适合系统教程
- **真人出镜**：亲切感，适合入门内容
- **故事叙事**：讲Git/Linus的故事，知识+情感

### 时长策略
- 短平快 2-8分钟：单点知识，完播率高
- 中长 15-25分钟：系统教程，收藏率高
- 超长 30-45分钟：深度串讲，建立权威

### 标签
- 平台活动标签：#AI新星计划 #青年创作者成长计划 #中视频新星扶持计划
- 垂直标签：#git #github #编程 #程序员
