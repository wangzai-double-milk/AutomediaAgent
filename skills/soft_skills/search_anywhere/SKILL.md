# Cross-channel Search Guide

供 research/operate workflow 选择渠道和评估证据。本资源不调用工具、不编排其他
capability，也不执行互动或发布。

## 流程

1. 明确缺口：事实、用户反馈、内容样本、视频表达或平台规则。
2. 选择 1–3 个最相关渠道，不为了“多平台”机械堆来源。
3. 优先使用能取得原文、原图或原视频的渠道，避免只读聚合摘要。
4. 对来源、时间和样本范围做标注；冲突信息继续核验。
5. 将渠道建议和证据标准交还当前 workflow。

## 渠道选择

| 信息需求 | 优先渠道 |
|---|---|
| 种草、消费决策、生活方式 | 小红书 |
| 短视频节奏、口播和镜头 | 抖音/B站等视频平台 |
| 实时讨论 | 微博等时效平台 |
| 官方规则和行业事实 | 平台官方页面或权威网站 |

## 纪律

- 不把搜索结果标题当作已阅读证据。
- 视频问题至少看一条真实视频，不能只读文字摘要。
- 关键结论保留 URL、标题或平台内容 ID。
- 无法访问时说明限制，不凭空补齐。
