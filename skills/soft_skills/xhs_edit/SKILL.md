# Xiaohongshu Visual

负责视觉素材的单步处理，不负责搜索、发布或完整工作流。工具契约以
`assets/tools_schema.json` 为准。

## 工具

| 工具 | 输入 | 输出 |
|---|---|---|
| `xhs_identify_dish` | 一张图片 | 品类与搜索关键词 |
| `xhs_image_review` | 原图；可选 3–5 张参考图 | `verdict`、问题、修图/重拍建议、标题方向 |
| `xhs_image_edit` | 原图 + 明确的局部修改列表 | 编辑后的本地图片 |
| `xhs_image_generate` | 具体画面描述 | 生成后的本地图片 |

单图可直接诊断；传参考图时才输出爆款共性、差距和对比式点评。不要假造数字评分。

## 审图判断

- `PASS`：主体、清晰度、光线和信息层级达到发布门槛。
- `REWORK`：曝光、色温、裁剪、背景干扰或封面文字可通过编辑修复。
- `REPHOTO`：失焦、严重遮挡、错误角度或主体结构问题只能重拍。
- 任一关键问题必须重拍时，不能用修图掩盖。

## 编辑纪律

1. 每条指令只描述一个区域和一个变化，避免互相污染。
2. 明确要求保留主体形状、纹理、品牌文字和未指定区域。
3. 多轮编辑始终回到 `original.*`，不在上一轮生成图上继续叠加。
4. 连续两轮仍未通过时停止美化，改为在原图上添加箭头与中文批注，交付重拍方案。
5. 输出必须写入当前任务目录，保留原图和每轮版本。

## 生成纪律

- 描述主体、场景、构图、光线、材质和画幅，不使用“高级感”等空词替代画面。
- 涉及真实商品时优先实拍或基于实物图编辑，避免生成错误包装与文字。
- 生成图是候选素材，必须再次审图后才能进入发布流程。

## 失败处理

- API、解析或素材加载失败：返回错误，不得当作 PASS。
- 部分媒体未成功载入：结果只能标为不完整，不得形成全量结论。
- 模型改变了禁止修改的区域：回到原图缩小指令范围，只重试一次。
