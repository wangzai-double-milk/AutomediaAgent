# xhs_edit_sop · P 图 / 修图 / 生图 / 批注示意图

> 触发：P 图 / 修图 / 改色调 / 加文字 / 调色 / 画批注 / 示意图 / 生图
> 后端：Seedream 4.5（`doubao-seedream-4-5-251128`）
> 入口工具：`xhs_image_edit`（i2i）/ `xhs_image_generate`（t2i）

## 1. 工具签名

### 1.1 修图（带原图，i2i）
```
xhs_image_edit(
  image: str,                       # 原图绝对路径
  edit_prompts: list[str],          # 多条指令会被拼成一段，越具体越好
  save_path: str = None,            # 不传默认落到 task_dir/edited_round{N}_{ts}.png
  size: str = '2K',                 # 1K / 2K / 4K 或具体宽高如 '1024x1024'
)
→ 返回新图本地路径
```

### 1.2 生图（无原图，t2i）
```
xhs_image_generate(
  prompt: str,
  save_path: str = None,
  size: str = '2K',
)
```

### 1.3 模型限制（Seedream 4.5）
- ❌ 不支持 `seed`
- ❌ 不支持 `guidance_scale`
- ✅ `size` 必须是 `1K/2K/4K` 或具体 `WxH`
- ⚠️ 不要换成 `doubao-seededit-3-0-i2i-250628`（默认未在方舟开通会 404）
- ⚠️ 接口首次调用超时概率约20%，无需修改参数直接重试1次即可成功

## 2. 修图（i2i）使用规范

### 2.1 prompt 拆细原则
**反例**（太宽泛，模型容易整体重绘把人脸/食物变形）：
```
edit_prompts=['让这张图更好看，加一些氛围感']
```

**正例**（每条都限定区域 + 动作 + 强度）：
```
edit_prompts=[
  '保持主菜（麻婆豆腐）的形状、纹理、颜色完全不变',
  '仅在画面整体偏暗的背景区域提亮 +15%，加暖光氛围',
  '在豆腐表面**仅**叠加一缕细细的蒸汽，强度 30%',
  '不要修改菜品本身的辣椒油和葱花',
]
```

要点：
- **第一条永远是 "保持 XXX 不变"** 的负向锁定
- 每条只动一个区域 / 一个属性
- 涉及强度的写百分比（"+15%"、"30%"），不要写"明显"、"大幅"
- "**仅**"、"**只**"加粗强调局部修改

### 2.2 P 图不止调色——文字 / 装饰也算
用户多次强调 P 图也包括"加文字让画面更好看"。模板：
```
edit_prompts=[
  '保持原图主菜和构图不变',
  '在图片左上角加一段中文白底黑字「秘制麻婆豆腐」，宋体加粗，留 20px 内边距',
  '右下角加一个小红书风格圆角标签「点赞收藏」，浅粉底白字',
]
```

### 2.3 review.edit_prompts 直接喂
`xhs_image_review` 返回的 `edit_prompts` 已经按 §2.1 规范写好（拼自 review prompt 模板），**直接传给 xhs_image_edit 就行**，不要再让 LLM"翻译加工"一遍。

### 2.4 修图归档（自动）
- 不传 `save_path` → 自动落 `task_dir/edited_round{N}_{ts}.png`
- 同一任务多轮 REWORK 会按 round 编号区分
- 不要再手动指定 `temp/image_review/...` 全局路径

### 2.5 多轮 REWORK 必须基于 original（硬纪律）
⚠️ 多轮 REWORK 时 `image=` 永远传 `task_dir/original.*`，**绝不**传上一轮的 `edited_*.png`。Seedream 多轮叠加会越 P 越坏，前一轮把光打过头，下一轮再"提亮"就直接成废片，审图会变成 REPHOTO。

每一轮：调整的是 **edit_prompts 文本**，不是输入图。

## 3. 批注示意图（REPHOTO 路径必用，详见 review_sop §Step 5a）

当 `verdict=REPHOTO` 时，**先**用 `xhs_image_edit` 在原图上画红箭头 + 中文标注，做一张"示意图"教用户怎么改。

### 3.1 批注模板
```
xhs_image_edit(
  image='<task_dir/original.jpg>',
  edit_prompts=[
    '在图片上用粗红色箭头和中文文字标注以下要点（保持原图内容不变，仅在图层上叠加标注）：',
    '主菜上方画一个红色箭头标注「这里要冒蒸汽」',
    '盘子右侧画红色箭头标注「加几片葱花点缀」',
    '画面整体偏暗的区域画虚线圈出，标注「补一束顶光」',
    # 视具体 review.gaps_vs_viral 灵活加
  ],
)
```

### 3.2 关键约束
- 第一条**必须**写「保持原图内容不变，仅在图层上叠加标注」否则模型会重绘
- 颜色固定红色（醒目，跟食物色不冲突）
- 文字用中文，不要英文（用户看不爽）
- 一次最多 3-4 条标注，再多画面会糊

## 4. 美食 P 图提示词灵感库（小红书高赞沉淀）

> 来源：从小红书爆款笔记搜集到的高复用 prompt 模板。**不是规则，是素材**——遇到对应场景时直接抄过来，按 §2.1 的"拆细 + 锁定"原则改成 `edit_prompts` 列表。

### 4.1 通用提亮增香（review.edit_prompts 给的最常见诉求 → 这套）
适用：色调灰、没食欲感、缺氛围

```
- 整体提亮 15%，暖色调饱和度 +10%，突出食物暖黄/红棕的食欲感
- 给主菜表面添加自然油光，增强食材纹理（红烧肉糖色光泽 / 蛋糕奶油绵密感 / 饮品冰珠气泡 任选）
- 适当添加细微的热气/蒸汽效果，强化刚出锅的新鲜感
- 背景适度虚化，突出主体美食，整体写实精致，光影自然
```

⚠️ 接到 `xhs_image_edit` 时**仍要按 §2.1 拆**：第一条加"保持主菜形状/纹理不变"，每条单独区域。

### 4.2 场景替换 / 补背景（用户原图背景拉胯时）
适用：背景是字节工位、办公桌、外卖盒等"破坏食欲"元素

```
保留原美食主体不变：
- 场景改为【木质餐桌 / 复古厨房 / ins 风桌面】（任选 1）
- 搭配【浅盘 / 复古餐具 / 桌布 / 小绿植 / 咖啡杯】等适配装饰
- 色调暖色系，温馨治愈，光影柔和，食物边缘与背景过渡自然
- 风格 ins 美食博主风，突出食物诱人质感，写实不夸张
```

### 4.3 手绘注解 Plog 风（高赞爆款样式）
适用：用户想要"附指令"那种带文字标注的氛围图（**这是当前小红书最爆的食物笔记风格**）

```
请观察这张美食照片中的元素，为每个物件加上有意义的手绘风注解：

【描写规则】
1. 白色笔画的细线手绘线条，一笔画风格，随性、略带不均匀感
2. 沿物件外围加描边轮廓，用箭头或虚线做视线引导

【文字规则】
1. 手写风格字体（日系可爱感）
2. 句子简短，像自言自语的小碎念，语气偏日记感、带一点情绪

【注解内容规则】
- 饮料 → 标注味道/温度/心情（例：清爽、微甜、刚刚好）
- 食物 → 标注口感/好吃程度（例：松软、超好吃、焦香酥脆）
- 空间 → 标注氛围（例：很放松、喜欢这种感觉、温馨治愈）
- 整体 → 最后加一句总结（例：今天有点幸福~、吃的超满足♡）

【装饰】适度加入热气、闪光、爱心、星星、小表情，不要过度，保留留白
【完成风格】像 Instagram 限时动态、杂志随手笔记，自然有质感带点慵懒
```

⚠️ 这套是**整图重绘式 prompt**，不像 §4.1/4.2 那样需要锁定主菜——因为本来就是要往图上加大量手绘元素。直接整段塞 `edit_prompts[0]` 即可。

### 4.4 反推参考图（拿到爆款想复刻时用）
适用：用 `xhs_image_generate` t2i 复刻爆款风格前先反推 prompt
**注意这是给 VLM 看的反推任务，不是给 Seedream 的修图 prompt**——用 `code_run` 直接调豆包 VLM：

```
分析这张美食参考图，生成能指导 AI 复刻的提示词，从以下维度全维度拆解：
- 主题内容：食物色泽、质感、诱人程度
- 场景设定：搭配的用餐/烹饪场景氛围
- 风格参考：写实 / ins 风 / 复古风，明确光影要求（"馋哭人的暖光"、"烟火气"）
- 色调色彩：主色调（暖黄/暖棕/清新冷调），如何突出食欲
- 构图视角：俯视 / 平视 / 45 度角，主体位置
- 细节补充：食物纹理（腊肠脂肪纹理 / 面包气孔 / 水果水珠）、环境光影
```

### 4.5 美食生图通用模板（t2i，配合 `xhs_image_generate`）
**填空式模板**，方括号都是要替换的占位符：

```
【主题内容】突出[色泽红亮 / 奶白诱人 / 新鲜清爽]的[具体菜品名]，呈现美味精致质感，传递满足感
【场景设定】布置在[木质桌面 / 复古厨房 / ins 风奶白桌面]，搭配[古朴砂锅 / 陶瓷餐盘 / 透明玻璃杯 / 餐垫 / 新鲜配菜]，营造[温馨生活化 / 烟火气 / 治愈清新]氛围
【风格参考】写实精致风，注重食材细节、色彩还原与质感，真实光影
【色调色彩】暖色调为主，[菜品主色]搭配配菜自然色，温暖有食欲，色彩层次丰富和谐
【构图视角】[俯视 / 45 度角 / 平视]，美食置于画面中心
【细节补充】细致刻画[菜品纹理：红烧肉肥瘦层次/表面糖色光泽 ｜ 蛋糕奶油气孔/水果颗粒 ｜ 饮品冰珠气泡]、盛器质感、桌面细微光影、配菜自然摆放，适当添加升腾热气
```

### 4.13 减脂清汤/热汤类专属修图拍摄模板（适用于减脂汤/水煮菜/轻食热餐等场景）
```
【拍摄技巧】
1. 容器：优先选高透细边玻璃碗/盘，避免花色厚重的陶瓷容器，最大化凸显食物清爽感
2. 构图：60°斜俯拍，碗占画面90%以上，背景只用浅白/浅米色素桌面；把核心减脂食材（肉/蛋/菌菇/蔬菜）分散铺在表面，不要全埋在汤里，缝隙点缀少量绿色葱花/香菜提色，角落可放1把金属勺增加层次感
3. 光线：选上午/下午窗边柔和侧自然光，避免正午强光直射（会出硬阴影）、避免背光拍（会发暗），光线能照出食材表面润感即可，不用额外打补光灯

【修图参数（可微调）】
- 亮度：+8~+12%，整体提亮避免画面暗沉显寡淡
- 高光：-10~-15%，压掉汤面、玻璃碗的过曝反光，保留食材质感
- 阴影：+15~+20%，提亮食材缝隙的暗部，让所有食材都清晰可见
- 对比度：-5~-8%，降低对比让画面更柔和，消除厚重感
- 色温：+3~+5%，微微偏暖凸显热食的暖胃感
- 饱和度：-3~-5%，降低整体饱和度避免色彩过艳显油腻
- 自然饱和度：+5~+8%，单独提鲜绿色的鲜亮感，提升食欲又不会让其他颜色失真
- 清晰度：+10~+15%，突出食材肌理、汤的气泡感，更有真实食欲
- 锐度：+5~+8%，不要加太高避免出现颗粒感
- 晕影：0，不加暗角保持整体通透感
```
来源：小红书2113赞牛肉口蘑汤减脂爆款笔记拆解

### 4.14 减脂餐合集类视频/图文专属运营模板（适用于多道菜谱/周期减脂餐爆款内容）
来源：本次拆解1838赞「连吃两周瘦7斤」减脂餐爆款笔记
适用：减脂垂类账号发多道菜谱合集、一周减脂餐、周期掉秤教程类内容
```
【视觉呈现要点】
1. 视频结构：「成品食欲预告+分步骤教程+N道菜快速展示」，用醒目标题卡/卡通转场区分每道菜，关键腌料/料汁配方直接打在画面对应步骤上，无需用户翻评论查找
2. 拍摄&修图要点：
- 容器选用普通家庭常用厨具（不粘锅/304不锈钢碗），不用精致特殊餐具，强化真实感降低距离感
- 打光用明亮柔和顶光/侧光，无硬阴影，整体低饱和暖调，高亮度低对比度，突出食材鲜亮感同时传递“干净天然无添加”心智
- 特意给「少油/喷油」操作步骤特写，强化低卡认知；食材搭配突出色彩对比（绿菜+高蛋白肉/豆制品），避免寡淡感
- 视频结尾加筷子夹菜的近景特写，放大食欲感
【文案&运营要点】
1. 标题公式：「具体周期+具体减重数字+核心逻辑」，例：「连吃两周瘦了七斤......吃的干净真的会瘦」，用可感知的效果数据精准戳中减脂用户痛点，点击率提升30%+
2. 开篇钩子：直接点明内容价值「N道低卡减脂餐，最后一道绝绝子」，明确告知有多个可复用菜谱，搭配“王炸款”预告大幅提升完播率
3. 话术技巧：
- 用减脂群体专属语境词：「管理期姐妹」「掉秤」「低卡高蛋白」，精准拉共鸣
- 每道菜配明确效果承诺：「狂吃一周腰围小一圈」「最近掉秤快全靠它」，给用户正向预期
- 弱化操作难度：「简单腌一下」「拌鞋底都好吃的料汁」，降低用户行动门槛
4. 数据提升技巧：单条内容放≥3道菜谱，价值感拉满，收藏率远高于单道菜笔记
```
适用：带浓稠酱汁的主食类，解决灰、暗、油光不明显的问题

## 5. 生图（t2i）使用场景

agent 主流程很少用 t2i——大部分时候用户已经有原图。t2i 只在以下场景用：

- 用户没图，让 agent 生成参考样张
- 给 PASS 的最终封面做"3 张样式变体"备选
- 教学场景（"如果是日料拉面应该这样拍"）

调用：
```
xhs_image_generate(
  prompt='日式豚骨拉面俯拍 45° 暖光木桌 鸡蛋纵切对半 浅景深 食欲色 4K 美食杂志风',
  size='1024x1280',  # 竖图（小红书友好比例 3:4）
)
```

## 6. 失败排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 修后菜品/人脸变形 | edit_prompts 太宽泛 | 第一条加"保持 XXX 不变"负向锁定 |
| 修后整体色偏严重 | 强度词太模糊（"明显增亮"） | 改成百分比（"+15%"） |
| 批注示意图被重绘 | 漏写"保持原图不变" | 第一条必须包含这句 |
| HTTP 404 模型未开通 | 用了 `doubao-seededit-3-0` | 切回 `doubao-seedream-4-5-251128` |
| size 报错 | 传了不支持的格式 | 用 `1K/2K/4K` 或 `WxH` |
| 想改 seed 复现 | Seedream 4.5 不支持 | 改 prompt 或加随机词，不要传 `seed` 参数 |
| 修图保存路径不对 | 老版本 ga.py 落到全局 temp/ | 已改为 task_dir 默认，确认 ga.py 是最新版 |
