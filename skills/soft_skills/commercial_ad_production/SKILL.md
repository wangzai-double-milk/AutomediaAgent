# 商业广告拍摄全流程 SOP

## 触发条件
当用户提及"拍广告""TVC""信息流""商业广告""硬广""产品视频""广告片怎么拍""商业拍摄"等关键词时，读取本SOP。

---

## §0 首先判断广告类型

商业广告分三大类，执行逻辑完全不同，必须先判断：

| 类型 | 目标 | 观众 | 时长 | 核心逻辑 |
|------|------|------|------|----------|
| **TVC（电视/品牌广告）** | 建立品牌印象 | 被动接收，大屏 | 15s-60s | 慢慢铺垫情绪，画面层次感强，刻在脑子里的是「感觉」 |
| **信息流广告** | 让人点击/购买/转发 | 主动滑动，碎片化 | 15s-30s | 前3秒决定一切，口播弹射，刻在脑子里的是「动作」 |
| **硬广（短视频卖货）** | 直接转化成交 | 平台推荐流 | 30s-90s | 帮用户解决问题顺便成交，去广告感 |

## §1 TVC 全流程（三阶段）

### 第一阶段：前期策划（Pre-production）——磨刀不误砍柴工

**1.1 Brief（工作简报）**：品牌方提供，明确：
- 市场目标：推广什么产品/服务？目标消费者是谁？
- 核心信息：最想传达的一句话是什么？
- 预期效果：品牌知名度 or 短期销量？
- 预算和档期：多少钱？什么时候上线？

**1.2 创意发想与提案**：广告公司创意团队（文案+美术）产出：
- 核心创意（Big Idea）：故事主线/核心概念
- 脚本（Script）：对话、旁白、情节描述
- 故事板（Storyboard）：手绘分镜，像漫画一样展示每个镜头
- 参考影片（Reference Video）：说明风格调性

**1.3 客户确认**：提案→选择/修改→敲定创意方向

**1.4 前期筹备**：
- 组建团队：导演、制片公司、摄影师（DOP）、美术指导
- 场地勘景（Recce）
- 选角（Casting）
- 服装/道具/化妆（FMC）
- 制作日程（Schedule）
- **召开PPM（制作前会议）**：导演+广告公司+客户确认所有细节，通常多次

### 第二阶段：中期拍摄（Production）——最烧钱的阶段

- 灯光组布光，摄影组架机器，美术组置景，演员化妆换装
- 导演：全场核心，指导表演和把握艺术效果
- 摄影师（DOP）：构图、运镜、灯光
- 场记（Script Supervisor）：确保镜头连贯性，避免穿帮
- 拍摄大量条（Take）供后期选择
- DIT（数据管理员）：当场备份整理素材，防止数据丢失

### 第三阶段：后期制作（Post-production）——精雕细琢的魔法

1. **剪辑**：粗剪（Rough Cut）→精剪（Fine Cut），反复调整节奏和镜头顺序
2. **视觉特效（VFX）**：无法实拍的特效画面
3. **调色（Color Grading）**：统一画面色彩，营造氛围
4. **声音设计**：配音（VO）+音效（SFX）+背景音乐（BGM）录制混音
5. **客户最终确认（Final Approval）**
6. **交付与投放**：按不同渠道输出对应格式

## §2 TVC vs 信息流：拍法四大差异

| 维度 | TVC | 信息流 |
|------|-----|--------|
| **开场** | 可慢热，用画面调情绪 | 前3秒必须给出冲突/痛点/利益，没第二次机会 |
| **口播节奏** | 可停顿，有呼吸感 | 口播要弹射，停顿一秒都是浪费 |
| **镜头复杂度** | 镜头语言丰富，可复杂 | 多小屏观看，简单干净才能看清 |
| **结尾逻辑** | 情绪收尾，品牌爆标 | 情绪之后必须有明确行动指引（点击/购买/领取） |

> ⚠️ 关键认知：信息流不是"降级版TVC"，而是"另一个物种"。品牌拿着信息流预算要求做TVC质感，拿着TVC质感要求做信息流效果——这是最常见的坑。

## §3 TVC脚本方法论

### 3.1 动笔前必答5问
1. 品牌是谁？
2. 卖给谁？
3. 最在意什么痛点？
4. 片子核心是什么？
5. 看完后希望观众做什么？

（每题一句话，想不清别写）

### 3.2 标准结构（40-50s版本）
```
开场(0-5s)   → 具体的人+具体场景（如"凌晨写字楼只剩一盏灯"）
冲突(5-15s)  → 生活细节+小崩溃（"她抬头看镜子，脸色暗黄"）
解决(15-25s) → 产品出现+使用过程+立刻变化
升华(25-40s) → 更好状态的她+新场景+情绪释放
标版(最后5-10s) → 产品定格+LOGO+Slogan+购买信息
```

### 3.3 新手7铁律
1. ✅ 一句话只干一件事
2. ✅ 能看见的才写（别写"内心挣扎"）
3. ✅ 少用形容词，多用动词（❌她很难过 ✅她把纸巾揉成一团）
4. ✅ 旁白口语化
5. ✅ 每个镜头3-5秒
6. ✅ 音乐提前定调（轻快/温暖/电子）
7. ✅ 脚本是给团队看的说明书，写得越清楚，拍得越接近

### 3.4 四大心法（资深编剧）

**心法一：抓住黄金前3秒**
- 痛点开场 > 自说自话
- ❌ "大家好，今天我们推荐的是..."（已划走）
- ✅ "你是不是也试过，深夜加班后，皮肤状态差到不想照镜子？"
- 把产品解决方案藏在用户痛点里

**心法二：构建故事骨架——情感永远胜过硬广**
- 经典结构：痛点共鸣 → 解决方案 → 证言背书 → 行动指令
- 常用故事模板：
  - 逆袭型："三年前的我VS现在的我"
  - 揭秘型："行业内不会告诉你的秘密"
  - 共情型："原来不止我一个人这样"
- 核心技巧：把产品特性转化为情感利益点
  - "含有玻尿酸"是特性 → "素颜敢开前置"才是买单理由

**心法三：视觉化写作——让文字在脑中成片**
- ❌ "产品很受欢迎"
- ✅ "办公室小姐姐们轮流借试用，连最挑剔的Lisa都偷偷问我在哪买"
- 用"画面感词汇"：普通"她用了护肤品"→视觉化"乳液推开瞬间，她在镜子里看见三年前大学时的自己"

**心法四：植入记忆点——让每个脚本都有高光时刻**
- 一句戳心文案（"你值得被看见"）
- 一个标志性动作（涂抹后的转身微笑）
- 一段听觉符号（特定的音效或旋律）

## §4 硬广视频方法论（短视频卖货）

核心认知：硬广卖货的本质是「帮用户解决问题，顺便达成交易」。

### 4.1 黄金圈倒置（替代"念说明书"式推销）
传统硬广：堆参数→讲产品→观众划走

**正确顺序**：
1. **为什么做**（初心/痛点）：先戳共性痛点，建立情感共鸣
   - 例：不说"我家祛痘精华很好用"，说"长又红又肿的大硬痘有多折磨人？不敢出门，镜子都不想照"
2. **怎么做**（研发过程）：建立信任
   - 例：讲"死磕38版配方，把刺激性成分全砍掉"
3. **做什么**（产品）：用「动比描」替代空洞形容词
   - ❌ "吸收快" → ✅ "它像水滴掉进沙漠一样，嗖地一下就钻进去了"

### 4.2 场景化软着陆
把产品"埋"进真实生活场景，让产品从「推销的主角」变成「解决问题的道具」：
- 祛痘精华放进「约会前突然爆痘，心态崩溃后拿出精华救急」的场景
- 卖酒不拍酒瓶子，把酒放进武侠叙事的饭桌、兄弟重逢干杯的场景

### 4.3 喇叭口流量结构
- **前5秒（宽口）**：用泛共鸣痛点撑开漏斗，稳住泛完播率
  - ❌ "脸上长痘痘的姐妹看过来"
  - ✅ "你有没有那么一个瞬间，越长大越怕照镜子？"
- **中后段（窄口）**：逐步收紧，抛出专业卖点、成分优势、下单理由

### 4.4 感官冲击拉满
购买欲不是说出来的，是被感官冲击点燃的：
- 火锅底料：拍「滚烫热油浇进辣椒堆，滋啦一声、白烟炸开」
- 祛痘精华：拍「切开红肿痘痘模型剖面，精华滴上去化开的挤压感」

### 4.5 视觉锤IP
设计专属的、可重复的标志性动作/视觉符号，每条视频重复：
- 永远不换的黄色T恤
- 结尾固定彩蛋（如被媳妇拍一下）
- 用完的空瓶"啪"一下拍在桌上

## §5 产品拍摄布光实操

### 5.1 核心原则：3分光，7分遮挡
多灯拍摄时单独控制每盏灯，避免灯光乱。不断尝试，哪缺补哪。

### 5.2 标准布光流程（以高反光金属饮料为例）
1. **背景光**：做渐变，营造产品和背景的层次分离（同色系产品尤其重要）
2. **侧逆光**：产品两侧对称柔光箱，打轮廓光
3. **顶光**：小面积束光筒，局部打亮顶部轮廓（最容易忽略的一步）
4. **斜下方补光**：打亮产品暗面，保留适当阴影塑造立体感
5. **细节处理**：少量凡士林涂抹产品，均匀喷洒水珠营造冰凉感
6. **吸光板遮光**：避免大面积柔光过度

### 5.3 高级布光理念
- 让打光"隐形"——看起来自然，其实精心设计
- 柔光勾勒产品高光，同时吸光板遮光避免过度
- 塑造产品轮廓的顶光最容易被忽略

## §6 低成本拍摄方案

### 6.1 手机拍摄商业产品图
**装备**：白色底台 + 一盏灯 + 三脚架 + 手机 + 产品

**核心技巧**：
1. **必须开2-3倍**：更接近人眼透视，不畸变（不开倍数镜头会有广角畸变）
2. **灯光不够PS来凑**：拍照片不用live，开RAW格式，狠狠拉曲线/色阶，白底图就是要白！阴影拉亮一些就通透
3. **LOGO叠加**：用图层混合模式更自然，双击图层→混合选项→下一图层混合按住alt拖动

### 6.2 产品Broll拍摄（五大运镜）
- 上下左右、前推后拉、环绕、旋转
- 电动滑轨（如洋葱工厂se）提升质感
- 设备参考：A7c一代/ZVE1 + FCPX剪辑

## §7 跟片执行（广告公司创意人员视角）

四大角色定位：

1. **桥的角色**：搭建导演和客户之间的沟通，避免客户和导演直接沟通。在两者意见中找平衡点——有些导演面对修改脾气很大，没中间人会让片场尴尬到死。

2. **服务员的角色**：跟片一般早8点到晚12点甚至更晚。给客户提供贴心服务——问想吃什么、需不需要咖啡、伙食不好帮点外卖、安排好商务车。客户舒适了，过内容也就快了。

3. **翻译的角色**：文字脚本变镜头语言，不同人理解不同。翻译清楚导演的意图给客户，同时听懂客户没表达清楚的修改意见。充分倾听客户意见，但不一定充分执行——有时候给意见只是他的工作而已。

4. **记录的角色**：每拍完一个镜头做好记录，主动跟客户确认。记好拍摄过程花费的时间，以免超时太多。

## §8 导演Treatment（以真实案例为例）

### 8.1 前期阶段
- 创意立意从品牌基因出发（如莲花跑车"FortheDrivers"），而非简单堆砌镜头
- 心态从"拍摄一辆车"转换到"表达一种状态"
- 前期会议沟通：主题讲解、影片结构设计、风格呈现、机器和运镜安排衔接

### 8.2 执行阶段
- 让后期老师提前跑一些剪辑内容（如Ending的时空能量之门、背景加入闪电、glitch效果）

### 8.3 后期阶段——磨细节
- **音乐**：脚本写完就定调（Techno/Dark ambient等）
- **音效**：加混响、空间渐强/弱效果。有趣技巧：倒放音效获得意外效果
- **剪辑结构**：不被motionboard框住，不断打破组合顺序——"你现在ABC的搭配，那不能ACB或者CAB的组合顺序呢？"

## §9 AI制作商业广告

### 9.1 全流程
```
前期准备（人物三视图保证一致性）→ 脚本制作 → 生成分镜 → 生成视频 → 音频制作
```

### 9.2 工具推荐
- **TapNow**：注册有免费额度，全套约5k积分
- **LibTV（里布TV）**：图片生成→视频生成→分镜拆解的全链路
- **核心流程**：上传模特图反推提示词→生成三视图→工具"灵感"选模板→"解析"拆脚本→生成分镜→视频→AI配音

### 9.3 关键认知
> "AI工具只是提升制作效率，它并没有降低创作的门槛。专业的商业TVC需要考验个人的审美能力、导演思维等，才能让demo级作品达到商业级。工具越强大，导演思维越重要。"

## §10 快速决策矩阵

当接到商业广告需求时，按以下顺序决策：

1. **判断类型**：TVC / 信息流 / 硬广 → 选对应方法论
2. **判断预算**：高预算走TVC全流程三阶段；低预算走手机拍摄+AI辅助
3. **判断是否用AI**：产品一致性要求高→实拍为主；创意/概念展示→AI可为主力
4. **脚本先行**：无论哪种类型，脚本是地基，花最多时间在脚本上
5. **跟片纪律**：桥-服务员-翻译-记录四角色缺一不可
