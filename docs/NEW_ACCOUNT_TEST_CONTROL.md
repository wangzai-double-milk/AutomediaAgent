# 账号与操作控制

账号健康、稳定身份、动作授权、发布节奏与防重分别检查。

- 主站读取真实稳定ID，创作中心身份需匹配。昵称不替代身份。
- 新账号不接收旧账号的稿件、队列或未完成任务绑定。
- 默认后台队列暂停，发布仅自己可见，两次发帖至少间隔600秒，无每日次数上限。
- 草稿、互动与修改不延长发帖间隔；仍需要对应动作授权。
- 角色/规则/素材改变时停止旧快照任务；不能直接发布过时母稿。
- 最终提交前保存输入与动作指纹，提交一次后独立回读内容、账号、目标ID与可见性。
- 未知发送或发布结果不自动重试，先保留记录并回读。
- 登录墙、验证码、账号风险或身份不匹配时停止，不通过换浏览器通路绕过。
- 页面切换或原生离开确认可能涉及未保存内容；先保留旧内容，不盲目确认离开。

这些是项目控制规则，不是平台公布的安全保证。具体字段与允许动作以工具实际回执为准。
密钥、Cookie、账号ID及提交记录留在本机，不写入公开Skills或Git。
