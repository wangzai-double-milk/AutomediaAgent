# 能力与边界

| 模块 | 已接入能力 | 使用边界 |
|---|---|---|
| 小红书研究 | 搜索、详情、可加载评论、作者与自己主页 | 需要正常登录及可用浏览器通路，不保证全量内容 |
| 内容制作 | 文字、看图、生图、改图、真实视频分析 | 需要对应模型权限，未载入媒体不视为已理解 |
| 审稿 | Thinking检查事实、语气、格式及图文，有界返工 | 不保证零错误；原稿与意见保留 |
| 小红书执行 | 内容准备、草稿、发布、管理与独立回读工具 | 当前self授权及600秒发帖间隔；未知结果不重发 |
| 抖音 | 搜索、阅读、播放器观察与视频理解 | 翻页依页面能力；未接入发布与互动 |
| 角色与记忆 | 角色版本、来源记忆、规则快照与冲突处理 | 日常配置复用不等于平台永不需要维护 |
| 消息与翻译 | 本地联系人、草拟、翻译、授权与回读契约 | 微信/QQ生产通道未连接 |
| 进程监督 | 会话内健康检查及有限恢复 | 不是已验收的系统登录自启动或24小时业务在线 |

真实发布、桌面工具和模型链路有历史验证，不保证当前账号或平台页面仍可用。
离线fixture不代表线上成功。先按[安装说明](installation_zh.md)完成环境与只读检查。
