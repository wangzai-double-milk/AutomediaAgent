# 当前能力与验证边界

更新：2026-10-28。这里区分代码接入、历史真实验证与本轮离线验证。历史成功不保证当前账号或新版网页仍可用；本地 UI 示例不代表平台执行成功。

## 内容与研究

| 能力 | 已完成 | 限制与未完成 |
|---|---|---|
| 文本 / 看图 / 生图 / 改图 | 真实模型接口与产物验证 | 需要对应模型权限；产物仍需审片 |
| 视频理解 | 真实视频输入、大小检查与媒体处理能力 | 媒体需成功载入；不凭标题推测整段画面 |
| 小红书推荐 / 搜索 / 筛选 | 真实页面、五组筛选、详情、作者与自己主页验证 | 不承诺全量分页或全评论；缺 ID 返回缺失 |
| 研究报告 | 任务目录、证据记录、去重与收敛工作流 | 需要逐条真实访问；工具超时必须保留缺口 |
| 抖音 / 其他网站 | 通用浏览器探索工作流 | 未建立专用发布闭环；最新双平台趋势研究受连接与回读超时影响，未称完成 |
| 方法沉淀 | 注册表、技能前置检查、个人方法资源 | 技能中的方法不是网页成功证据 |

## 小红书执行

真实验收主要使用 macOS、系统辅助功能与已登录 Chrome；CDP 扩展仍需独立连接和验收。

| 功能 | 历史真实证据 | 边界 |
|---|---|---|
| 图文 | 单图、多图、话题、草稿恢复、self 发布、编辑回读与删除 | public 实际发布、独立媒体像素核对未验收 |
| 视频 | 4秒 MP4 上传、编辑、草稿恢复、self 发布、管理回读与删除 | 发布后逐帧播放质量未核对 |
| 长文 | 原文回读、一键排版、草稿恢复、self 发布、描述回读与删除 | 全部排版图片像素未核对 |
| 播客 | 601秒音频与封面上传、草稿恢复、self 发布、管理回读与删除 | 发布后音频逐秒质量未核对 |
| 可见性 | self 发布；self → friends → self 修改与回读；public 候选读取 | public 最终提交未验收 |
| 定时 | 实际未来时间提交，管理与编辑页独立核对 | 不依赖占位时间；旧测试已清理 |
| 点赞 / 收藏 / 关注 | 提交、独立核对、恢复原状态 | 限身份与共享额度，不承诺批量可靠性 |
| 评论 / 指定回复 | 自有测试单次提交、目标线程核对与清理 | 需要真实作者 ID 和原文；深层批处理未验收 |
| 作品管理 | 真实作品 ID、标题与账号绑定；修改、可见性与删除 | 自有测试证据；平台入口变化需重验 |
| 四类草稿 | 列表、打开、保存、删除、直接恢复发布 | 新账号测试模式禁止旧本地草稿 publish/delete，不能因昵称相同转移归属 |
| 任务队列 | 持久化、锁、入队/领取/提交、中断只读核对 | 默认后台暂停；running/uncertain 不自动重发 |
| 普通合集 | 创建、图文草稿绑定、保存重开与列表核对 | 简介未独立核对；部分管理入口网页未提供 |
| 播客合集 | 单合集创建、编辑、修改、空合集删除 | 多目标卡片定位未完成真实验收 |
| RSS | 地址、时间、合集、邮箱、验证码与协议表单读取/预填 | 缺真实材料，最终导入未验收；菜单项不等于已选值 |
| 私信 | 会话读取、预填、核对并清除 | send 代码已接入，实际发送未验收 |
| 数据 / 商业 / 资料 | 可见粉丝页与入口发现 | 账号概览、内容分析和商业权限未完整开放或验证 |

## 工作台与执行控制

Studio 已实现底部可调高对话、四工作区、状态角色、素材筛选与聚焦、灵感组合、导演便笺、额度与队列摘要，以及可展开的执行进展卡。桌面和窄屏使用隔离页面验证；当前验证记录见[本轮验证](RELEASE_VALIDATION.md)。

`preview` 只预填，`save_draft` 是写操作，发布默认 `visibility=self`。`deferred` 表示未提交并需等待额度，`restricted/unavailable` 表示权限或平台状态不允许，`unverified` 表示结果不确定。工具返回记录不自动等于任务成功。

账号健康、主站稳定 ID、创作中心身份、共享额度和操作 journal 都是执行前提。规则见[账号与测试控制](NEW_ACCOUNT_TEST_CONTROL.md)。运行记录与具体账号证据留在本机，公共分发不携带私人账号状态。
