## 旧界面问题与修复

实际 Chrome 原先在14169保留旧布局；同端口HTTP返回的页面与脚本已经是新版。
14168另有旧进程，新资源请求返回404。两项证据表明页面没有重新载入及旧实例并存，
不能据此认定源码存在两套相互冲突的前端。

修复后 HTML 不缓存，样式/脚本地址携带内容哈希，启动时打开当前界面版本地址。
已从用户实际 Chrome 窗口确认暖色小片场、四工作区、底部对话和发布节奏面板。
只重启本轮创建且无运行任务的新版实例；原有旧进程未擅自终止。
